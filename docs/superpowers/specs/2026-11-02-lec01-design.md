# 第1回 発展＋α：承認済み設計

2026-11-02、ユーザーが案Aと以下の設計を承認し、環境準備から実装まで依頼した。

## 目的と比較方法
2モデル×3質問×3回、計18回を基本とし、API呼び出し全体の経過秒数、入力・出力トークン数、回答本文を保存する。
質問はLoRA、宿題の3レベル、第2回の内容。一般知識と講座固有の情報を区別する。
成功した呼び出しの中央値・最小・最大を集計する。失敗は分離して保存する。
正確さは用語集と講義資料を根拠に人が判定する。資料はモデルへ渡さない。
3回の結果を一般的な性能ランキングと解釈しない。

## 検討した方法
- 選択したA：反復比較と資料との照合。条件ごとのばらつきを学べる。
- B：資料あり／なしの比較。入力条件を増やすため今回は実装しない。
- 手動実行：簡単だが記録漏れが起きやすい。自動記録方式を採用する。

## 実装方針
講座のPythonとgoogle-genaiを使い、依存バージョンを変更しない。
JSONLで1回ごとに記録し、同じ条件の再開時は既存の試行を飛ばす。
エラーを成功値に混ぜず、失敗した試行も自動で繰り返さない。
モデルは実行時に指定し、現在の利用可否・上限をAI Studioで確認する。
キーをコードやログに書かない。測定コードのテストは偽の応答を使い、実験データと明確に区別する。
提出先は自分のforkのlec01からmain。API実測・人による評価・PR提出は未実施なら未実施と記す。
